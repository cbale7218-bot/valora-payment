# VALORA — GitHub Pages

Это простая версия сайта VALORA, полностью подходящая для GitHub Pages.

## Структура

```text
VALORA/
├── index.html
├── config.js
└── assets/
    ├── valora-logo.png
    └── qr.png
```

## Главное правило

Все данные, которые нужно регулярно менять, находятся в:

```text
config.js
```

HTML трогать для изменения реквизитов не нужно.

## Что можно менять в config.js

- название банка;
- имя получателя;
- номер счёта;
- IBAN;
- SWIFT/BIC;
- назначение платежа;
- сумма;
- валюта;
- Telegram;
- QR-код;
- заголовки;
- описания;
- текст после оплаты;
- тексты кнопок;
- текст внизу сайта.

## Как заменить QR

1. Создай/подготовь QR-код.
2. Назови его `qr.png`.
3. Открой папку `assets` в GitHub.
4. Загрузи туда новый `qr.png`.
5. В `config.js` оставь:

```javascript
qrImage: "assets/qr.png",
```

Если хочешь другое имя:

```javascript
qrImage: "assets/my-qr.png",
```

## Как менять реквизиты через GitHub

Открой:

```text
config.js
```

Нажми:

```text
Edit this file
```

Измени нужные значения.

Внизу нажми:

```text
Commit changes
```

После этого GitHub Pages автоматически обновит сайт.

## Важно

Эта версия специально сделана без backend и базы данных, поэтому отлично подходит для GitHub Pages.

Публичный сайт не содержит отдельной админ-панели. Управление происходит через GitHub.

Если репозиторий приватный, GitHub Pages зависит от типа твоего GitHub-плана/настроек. Для публичного репозитория обычный вариант GitHub Pages подходит.

## Публикация

В репозитории:

```text
Settings
→ Pages
→ Build and deployment
→ Source: Deploy from a branch
→ Branch: main
→ Folder: / (root)
→ Save
```

Через некоторое время GitHub выдаст адрес сайта.

## Важно про безопасность

Не помещай в `config.js`:
- пароли;
- API keys;
- секретные токены;
- приватные данные клиентов.

Этот файл является частью публичного сайта.
